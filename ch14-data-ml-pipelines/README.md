# Chapter 14. Data and ML pipelines: Data in, answer out. The rest is plumbing.

> Data in, answer out; the rest is plumbing. Three prompts map every stage a pipeline runs, open the code inside each, and trace one input end to end.

## The prompts

Copy any of these into ChatGPT, Claude, Gemini, or an agent like Claude Code, with the repository you want to read open alongside it. They're reproduced verbatim from the chapter, so what you run is what you read.

- [`01-ask-the-llm-to-map.md`](prompts/01-ask-the-llm-to-map.md) — Ask the LLM to map the six stages
- [`02-open-each-stage-and-read.md`](prompts/02-open-each-stage-and-read.md) — Open each stage and read the code inside it
- [`03-trace-one-clip-through-the.md`](prompts/03-trace-one-clip-through-the.md) — Trace one clip through the code

## Running them

Each prompt is self-contained. Point it at one repository at a time and paste in the files it asks for under **Input**; an agent can gather those itself if you give it the repo path.

The chapter walks through the answers these produced on the example repository, pinned to a specific commit. Your repository will differ, which is the point.
