# Chapter 17. Folder structure: The floor plan of your codebase

> The floor plan of your codebase. Three prompts name a repo's layout from its root, open each folder to tell a contract from a junk drawer, and trace one ticket through every layer.

## The prompts

Copy any of these into ChatGPT, Claude, Gemini, or an agent like Claude Code, with the repository you want to read open alongside it. They're reproduced verbatim from the chapter, so what you run is what you read.

- [`01-read-the-root-deduce-the.md`](prompts/01-read-the-root-deduce-the.md) — Read the root: Deduce the layout pattern
- [`02-open-each-folder-contract-or.md`](prompts/02-open-each-folder-contract-or.md) — Open each folder: Contract or junk drawer?
- [`03-trace-one-ticket-across-every.md`](prompts/03-trace-one-ticket-across-every.md) — Trace one ticket across every layer it touches

## Running them

Each prompt is self-contained. Point it at one repository at a time and paste in the files it asks for under **Input**; an agent can gather those itself if you give it the repo path.

The chapter walks through the answers these produced on the example repository, pinned to a specific commit. Your repository will differ, which is the point.
